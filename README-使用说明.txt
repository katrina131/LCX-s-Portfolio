============================================
  秋招作品集网站 · 使用与保管说明
============================================

【文件构成】
- index.html          → 网站本体（双击就能在浏览器打开预览）
- assets/             → 存放你的图片素材
- README-使用说明.txt  → 本说明

【怎么保管（重要！）】
1. 把整个文件夹存到你的个人网盘 / 私人邮箱（防止公司账号失效后丢失）。
2. 每次改完内容，都更新一份到网盘。
3. 换电脑或换账号后，把这个文件夹上传给 AI，就能继续修改。

【怎么修改内容】
- 用记事本或 VSCode 打开 index.html
- 按 Ctrl+F 搜索“替换”两个字，每处待填内容都有标注
- 改文字：直接替换中文
- 换图片：图片放进 assets/，把占位块换成 <img src="assets/图片名.jpg">
- 换视频：用 B站/腾讯视频/YouTube 的嵌入 iframe 链接替换占位块

【怎么让别人看到（印在简历上）】
把整个文件夹传到 Vercel 或 Netlify（用个人邮箱注册，免费），
即可得到一个永久网址，随时可更新。
